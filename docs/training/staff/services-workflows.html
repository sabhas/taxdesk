Services and workflows

Set these up before anyone opens a case. A workflow defines the statuses and checklist a case follows. A service is something the firm sells (for example "Individual income tax return"), with a default fee, deadline, and workflow.

Setup order

  1. Create a workflow template and publish a version.
  2. Create a service that uses that template as its default workflow.
  3. Now cases can be opened for that service.

Workflow templates

Open Workflows → New template → Create template. New templates start as draft version 1, pre-filled with the starter annual-return workflow below.

Editing a draft

  • Statuses: each has a name, a key (for example in_review), a kind, whether it is the initial status, and whether it needs the checklist complete. Use Add status.
  • Allowed transitions: which status may move to which.
  • Checklist: ordered items with a document type, required flag, "reviewer must verify" flag, and instructions. Use Add checklist item.
  • The editor flags problems as you type: not exactly one initial status, a status nothing can reach, or a dead end.
  • Save draft, then Publish version N. Publish is disabled while there are unsaved changes or problems.
Published versions never change

Once published, a version is frozen. To change it, select Start new draft, edit, and publish a new version. Existing cases keep the version, statuses, and checklist they were opened with. Only new cases pick up the new version.

Services

Open Services → New service and fill in:

Name, DescriptionFor example "Individual return".
Default fee (PKR)Pre-fills the first line of an invoice created from a case
Default deadline (days)A new case's due date = today (firm timezone) + this many days
Duplicate open cases Warn: a second open case for the same client, service, and tax year needs a reason. Block: it is refused.
Default workflowA template with at least one published version

Select Create service (or Save service when editing). Archive retires a service. Its cases are kept, and Restore brings it back. Changing a service's fee or deadline never changes cases already open.
