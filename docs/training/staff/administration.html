Users

Users lists everyone, with their Name (display name and username), Role, Status (Active, Invited, Deactivated), and MFA (Enabled or Not set up).

TaxDesk sends no email

Activation and reset links are shown to you once. You deliver them yourself: in person, by phone, or through the firm's private chat. Never post them in a group channel.

Invite a user

  1. In the Invite a user card, enter a Username (permanent, cannot be changed later, for example a.khan), a Display name, and a Role.
  2. Select Send invitation.
  3. A One-time link card appears with the full link and its expiry time. Select Copy link, deliver it, then Dismiss.
  4. The person has 30 minutes to open it. If they miss it, use Reset link on their row to make a new one.

Change role, reset, deactivate

Action How Effect
Change role Pick a new role in the row's dropdown. It applies immediately, with no Save button. The user is signed out everywhere and sees the new role's menu next time
Reset Reset link, then deliver the one-time link The user sets a new password through the link. Their sessions end.
Deactivate Deactivate, then confirm in Deactivate <name>? Sessions end immediately and sign-in stops. Their history and audit trail are kept.
Reactivate Reactivate The user can sign in again
Do not lock yourselves out

Keep at least two active administrators with MFA. If the last one is locked out, an operator has to run the offline recovery tool (see lockouts).

Firm settings

Everyone can open Firm settings. Only administrators can change it; others see "Your role can view but not change firm settings."

Field Rules Default
Firm name Shown across the app Set at bootstrap
Timezone Any IANA zone. Shortcuts: Asia/Karachi, UTC, Asia/Dubai, Europe/London, America/New_York. It drives due dates, "overdue", and "this month". Asia/Karachi
Currency PKR only for now PKR
Invoice number prefix 2–6 capital letters. Applies only to numbers issued after the change. INV (for example INV-00001)
Receipt number prefix 2–6 capital letters RCP
Document size limit (MiB) 1–250. The effective limit is the lower of this and the deployment's ceiling. 250
Dashboard due-soon window (days) 1–60. Used by the "Due soon" queue and the dashboard. 7

Select Save settings. Each change is audited with its old and new values. If someone else saved in the meantime you get a conflict and must reload.

Firm logo

The Firm logo card on Firm settings holds the logo printed at the top left of invoice and receipt PDFs, above the firm name. Everyone can see the current logo; only administrators can change it, and others see "Your role can view but not change the firm logo."

  1. Choose a file under Logo image (or Replace with when a logo exists). Use a PNG or JPEG of at most 512 KiB and at most 2000 pixels on each side. A wide logo on a white or transparent background prints best.
  2. Select Upload logo (or Replace logo). The preview updates and "Logo saved. New invoice and receipt PDFs will show it." appears.
  3. To go back to no logo, select Remove logo and confirm.

Only PDFs created after a change use the new logo. A PDF that already exists is never regenerated, so older invoices and receipts keep the logo they were made with. TaxDesk checks the file itself, not its name: a renamed GIF or SVG is refused with "Use a PNG or JPEG image.", and a damaged file with "This image could not be read." Each upload, replacement, and removal is audited (firm.logo_updated, firm.logo_removed) with the file type, size, and a fingerprint of the image. If someone else changed the settings in the meantime you see "Settings changed" and must reload.

Document storage

Document storage connects the firm's OneDrive once, shows its health, and runs reconciliation. The buttons are Connect storage / Reconnect storage, Check now, Disconnect, and Run reconciliation. The details, states, and setup are in OneDrive document storage.

When storage needs attention, staff see "Document storage is unavailable" on document panels, and administrators get a reconnect button right there.

Audit history

Every material change is recorded permanently: sign-ins and failures, user changes, client, case, document, and billing changes, exports, imports, and settings. Nobody can edit or delete an audit event.

  • Filters: From date, To date, Action, Actor user ID, Entity type, Entity ID, Request ID. Then Search or Clear.
  • Action wildcards: billing.* finds every billing event, and auth.* every sign-in event.
  • Columns: When, Actor, Action, Entity, Changes, Request. Use Load more for older events.
  • Sensitive values are masked. Identifiers show as, for example, •••••-••••567-1, and secrets never appear.
  • The request ID links an error message a user saw to the exact audit event and server log line.

Useful actions to know:

firm.bootstrappedThe firm was created
auth.login_failedA failed sign-in (watch for spikes)
user.recovery_*An operator used the offline recovery tool
client.created, case.createdNew records, including from imports
billing.invoice_finalizedAn invoice got its number
import.row_decided, import.committed, import.exceptions_exportedData import activity

Administrator routine

  • New joiner: invite with the smallest suitable role, and check MFA shows Enabled the next day.
  • Leaver: deactivate on their last day, reassign their clients and cases, and remove their share of the OneDrive app folder.
  • Weekly: check storage health, and run reconciliation if anything looks off.
  • Monthly: review users (anyone still Invited or with MFA Not set up?) and scan audit history for auth.* failures.
