Role quick-reference cards

One card per role, to print and keep by the desk. Each card prints on its own page (use ⎙ in the top bar).

Administrator quick reference

People

  • Invite: Users → Invite a user → Send invitation → Copy link
  • Links work once and expire in 30 minutes. Deliver them yourself.
  • Forgot password: Reset link
  • Leaver: Deactivate (sessions end at once)
  • Role change applies immediately and signs the user out

Firm

  • Firm settings: timezone, prefixes (2–6 capitals), upload limit, due-soon days, firm logo (PNG/JPEG, 512 KiB)
  • Document storage: Check now, Reconnect storage, Run reconciliation
  • Data import: dry run → decide → commit with the same file

Investigate

  • Audit history: Action billing.*, auth.*
  • Paste a user's request ID into Request ID
  • Keep two administrators with MFA at all times

Manager quick reference

Clients

  • Search before New client
  • Same CNIC/NTN is blocked. Similar name: give a reason → Create anyway.
  • Always set the Assigned manager
  • Group a client under its head: Edit → Parent client (one level only)
  • Bill a whole group: group head's page → Create combined invoice
  • Conflict screen: read theirs before saving over

Cases

  • Queues: Team, Unassigned, Due soon, Overdue
  • Assign a consultant and a different reviewer
  • Whoever completed an item cannot verify it
  • Archive only completed or cancelled cases
  • Services and Workflows: Publish version N; published versions never change

Money

  • You can read invoices and Reverse payments (with a reason)
  • You cannot draft invoices or record payments
  • Reports → Export CSV (audited)

Consultant quick reference

Daily

  • Dashboard → Overdue → Due soon → My work
  • You see clients you manage and cases assigned to you
  • Open case: you must be the primary consultant

Documents

  • Upload document → file, checklist item, type
  • PDF, JPEG, PNG, DOCX, XLSX, CSV
  • Dropped connection: Retry continues where it stopped
  • The reviewer (or a manager) verifies documents

Checklist and status

  • As preparer: Complete / Reopen
  • As reviewer: Verify / Return (comment required)
  • Greyed-out status button: read the reason under it
  • Filed locks the checklist

Billing quick reference

Invoice

  • Case or client page → Create invoice
  • From a case, the first line is the service and fee
  • Save draft → Finalize… → Finalize invoice
  • INV numbers never skip, and finalized invoices never change
  • "PDF could not be stored" → Generate PDF again

Payments

  • Record payment: amount, method, received on, reference
  • Partial is fine; more than outstanding is refused
  • Receipt (RCP) on each payment row
  • Wrong payment? Ask a manager to Reverse it.

Fixing mistakes

  • Void needs no net payments, a reason, and confirmation
  • Wrong finalized invoice: void it, then create a new one
  • Reports → Billing → Export CSV

Read-only quick reference

You can

  • Search clients and open cases
  • Open documents (every open is recorded)
  • Read invoices, reports, and the dashboard
  • Export report CSVs (audited)

You cannot

  • Create, edit, archive, upload, or pay
  • See users, audit history, or settings changes

Everyone

  • Sign in with a username, then a 6-digit code
  • 30 minutes idle or 12 hours: sign in again
  • Lost phone: use a recovery code, then Security
