Documents

Upload client files once, link them to the checklist, review them, and open them whenever needed. Files are stored in the firm's OneDrive, but you only ever use them through TaxDesk.

Administrator Manager Consultant upload, review, and delete · Read-only opens · Billing has no document access

Where documents live

Every client page and case page has a Documents panel. A document always belongs to a client, and optionally to a case and one of its checklist items.

Upload a document

  1. In the Documents panel, select Upload document.
  2. Choose the File. Allowed types are PDF, JPEG, PNG, DOCX, XLSX, and CSV, up to the firm's limit (250 MiB by default). Unsafe file names and other types are refused before anything is sent.
  3. On a case, pick the Checklist item it satisfies. Pick the Document type (for example "Bank statement").
  4. Select Upload. The file goes in 5 MiB pieces with a progress bar.

Retrying the last step never creates two copies of the same document.

Open and edit

  • Open downloads the file through TaxDesk. Your access is checked again on every open, so a deactivated or reassigned user cannot use an old link. Every open is recorded in the activity history.
  • Edit, then Save, changes the document type or checklist link. It never changes the file itself.

Find a file in OneDrive

If the TaxDesk folder is shared with you in OneDrive, you can read files there too. Files are filed by the codes shown in TaxDesk:

  • Case documents: clients → CL-00001 → 2025 → TC-00042
  • Documents with no case: clients → CL-00001 → general
  • Invoices and receipts are in the same folders, named by their number, for example INV-00012.pdf.
  • If two files had the same name, OneDrive adds a number to the later one, for example bank-statement 1.pdf.

Only read files in OneDrive. Upload, edit, and delete in TaxDesk. A file moved, renamed, or deleted in OneDrive is reported as moved or missing.

Who can review: on a case document, the case's reviewer or a manager/administrator. The preparer cannot verify documents on their own case. On a client-level document, managers and administrators.

Documents and the checklist

A required checklist item that names a document type can only be completed when it has at least one linked, verified document. If that document is later rejected, reset, unlinked, deleted, or found missing, the item reopens automatically on open cases, and the change is logged.

Delete and restore

  • Delete (confirmed with Delete document) moves the file to OneDrive's recycle bin and hides the record. Its history stays.
  • Turn on Show deleted documents to see deleted ones.
  • Managers and administrators can Restore a deleted document while OneDrive can still recover it from the recycle bin.

When storage is unavailable

If you see Document storage is unavailable, uploads, opens, deletes, and restores stop with a clear message, while the rest of TaxDesk keeps working. Short outages fix themselves. If it says a reconnect is needed, an administrator selects Reconnect storage.

What documents do not do (yet)

  • No text recognition (OCR) or searching inside files.
  • No editing files in the browser.
  • No virus scanning. Only accept files from known sources.
  • Invoice and receipt PDFs are stored separately and never appear in document lists.
