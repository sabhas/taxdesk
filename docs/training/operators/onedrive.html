OneDrive document storage

Document files are stored in the firm's OneDrive (Personal) account, in a private app folder. TaxDesk keeps the file's metadata and its OneDrive item ID, never the file contents and never a OneDrive path.

How it works

  • An administrator connects OneDrive once per environment. Staff never sign in to Microsoft. Every upload and download goes through the API Worker.
  • TaxDesk asks only for Files.ReadWrite.AppFolder and offline_access, so it can see its own app folder and nothing else in the account.
  • Tokens are encrypted with STORAGE_TOKEN_ENCRYPTION_KEY and refreshed automatically. If consent is revoked, TaxDesk stops document actions and asks an administrator to reconnect.
  • Files are uploaded in 5 MiB pieces through a resumable session (the TD-005 spike proved 320 KiB-multiple chunks, resumable sessions, and reconnect detection).

1. Register a Microsoft app (once per environment)

  1. Sign in to the Microsoft Entra admin center and open App registrations → New registration.
  2. Name it after the environment, for example TaxDesk staging.
  3. Set Supported account types to Personal Microsoft accounts only, so the authority is consumers.
  4. Add the redirect URI <APP_PUBLIC_URL>/settings/storage/callback. For example: http://localhost:5173/settings/storage/callback locally, or https://staging.taxdesk-web-staging.pages.dev/settings/storage/callback on staging.
  5. Under API permissions → Microsoft Graph → Delegated, add only Files.ReadWrite.AppFolder and offline_access.
  6. Copy the Application (client) ID.
Public or confidential client

TaxDesk uses authorization code + PKCE, and the Worker redeems the code on the server. A public client needs no secret. If Microsoft refuses the exchange because a client secret is required, the redirect was registered as a confidential "Web" app. Either create a client secret and set it as ONEDRIVE_CLIENT_SECRET, or register the redirect as a public client. The app adapter has not yet been run against a real account outside the TD-005 spike, so record which option you used in the staging evidence.

2. Configure the Worker

# wrangler.toml, in the environment's vars section
ONEDRIVE_CLIENT_ID = "<application (client) id>"
APP_PUBLIC_URL = "https://<web host>"
# ONEDRIVE_AUTHORITY = "consumers"   # default

# secrets
pnpm exec wrangler secret put STORAGE_TOKEN_ENCRYPTION_KEY --config packages/api/wrangler.toml --env staging
# only for a confidential registration:
pnpm exec wrangler secret put ONEDRIVE_CLIENT_SECRET --config packages/api/wrangler.toml --env staging

Locally, put the same names in packages/api/.dev.vars. Redeploy (or restart pnpm dev:api) after changing them.

3. Connect from the app

  1. Sign in as an administrator and open Document storage.
  2. Select Connect storage, sign in with the firm's Microsoft account, and approve the consent screen.
  3. You return through Finishing connection… to the storage page, which now shows Connected, who connected it, and when.
  4. Select Check now to confirm health.

Connection states

Status Meaning What to do
Not connected No account is connected yet, or it was disconnected Connect storage
Connected Healthy Nothing
Temporarily unavailable Microsoft had a short outage or throttled TaxDesk Wait. TaxDesk retries and recovers on its own. Use Check now later.
Reconnect required Consent was revoked, expired, or the password changed Reconnect storage with the same Microsoft account. Existing documents keep working afterwards.

"Not configured" (HTTP 503 STORAGE_NOT_CONFIGURED) means the Worker has no ONEDRIVE_CLIENT_ID. That is a deployment fix, not an in-app one.

Reconciliation

Run reconciliation checks every document record against OneDrive and reports how many were checked, missing, moved, and recovered. Missing files are flagged Missing in storage. Nothing is ever deleted automatically. Run it weekly, and always after a database restore.

Rules for the storage account

  • Use a firm-owned Microsoft account, not someone's personal one, and protect it with MFA.
  • Use a different account for staging and production.
  • Never move, rename, or delete files in the TaxDesk app folder by hand. Reconciliation would flag them as missing or moved.
  • The OneDrive recycle bin is what makes restore possible. Once Microsoft empties it, a deleted document can no longer be restored.
  • Watch the account's free space: an upload fails when the quota is reached.
