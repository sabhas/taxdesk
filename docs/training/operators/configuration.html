Configuration and secrets

Every value TaxDesk reads, where it lives in each environment, and what happens if it is missing or changed.

One secret set per environment

Generate new values for development, staging, and production. Never copy a key from one environment to another, never commit one, and never paste one into chat or a ticket. A missing secret makes the dependent feature return 503. It never turns the protection off.

API Worker secrets

Set with pnpm exec wrangler secret put <NAME> --config packages/api/wrangler.toml --env <staging|production>. Locally, put them in packages/api/.dev.vars.

Name Purpose If lost or changed
MFA_ENCRYPTION_KEY Encrypts every user's TOTP secret Nobody's authenticator works any more. Every user must go through auth:recover … disable-mfa and enrol again.
CLIENT_DATA_ENCRYPTION_KEY Encrypts client CNIC and NTN values Stored identifiers can no longer be decrypted. Treat it as irreplaceable.
CLIENT_IDENTIFIER_INDEX_KEY A different key for the identifier "blind index" used for duplicate blocking and exact CNIC/NTN search Duplicate detection and identifier search silently stop matching. Never rotate it without re-indexing every client.
STORAGE_TOKEN_ENCRYPTION_KEY Encrypts OneDrive tokens and upload-session handles An administrator reconnects storage. No documents are lost.
TURNSTILE_SECRET_KEY Verifies the Cloudflare Turnstile challenge after repeated failed sign-ins Throttled sign-ins return 503 until it is set
ONEDRIVE_CLIENT_SECRET Only for a confidential Microsoft app registration. Public clients use PKCE. Storage connection and token refresh fail

Generate each 32-byte key separately:

openssl rand -base64 32 | tr '+/' '-_' | tr -d '='

Store a copy of every key in the firm's offline key store (for example a password manager vault owned by the firm, not a person). Restores need the same keys.

API Worker variables (not secret)

Set in packages/api/wrangler.toml under [vars], [env.staging.vars], or [env.production.vars].

Name Purpose Default
ENVIRONMENT development, staging, or production Set per environment
RELEASE_VERSION Shown by /health. CI sets it to the deployed commit SHA. 0.0.0 locally
APP_PUBLIC_URL Base URL of activation and reset links, and of the OneDrive redirect URI (<APP_PUBLIC_URL>/settings/storage/callback) The request origin. Set it explicitly once storage is used.
APP_ORIGIN Extra comma-separated origins accepted by the Origin check on changes None
TURNSTILE_SITE_KEY Public Turnstile site key sent to the browser None
ONEDRIVE_CLIENT_ID Application (client) ID of this environment's Microsoft app registration None. Storage is "not configured" without it.
ONEDRIVE_AUTHORITY Microsoft identity tenant segment consumers (OneDrive Personal)
DOCUMENT_MAX_UPLOAD_BYTES Hard upload ceiling. The firm setting can lower it but never raise it above this. 262144000 (250 MiB)

API Worker HYPERDRIVE development: placeholder ID plus localConnectionString; staging: 2c20141d82af41759636c76e43c0da4c; production: still the placeholder REPLACE_WITH_PRODUCTION_HYPERDRIVE_ID

The Worker has no KV, R2, or D1 binding. R2 is used only by the backup workflow.

GitHub environment secrets and variables

These live in the protected staging GitHub environment (later the same names in production). Pull-request workflows can never read them.

Name Kind Purpose
CLOUDFLARE_API_TOKEN, CLOUDFLARE_ACCOUNT_ID Secret Deploy the Worker and Pages
STAGING_DATABASE_URL Secret Run migrations and the posture check during deploy
PLATFORM_POSTURE_EVIDENCE_JSON Secret The operator's signed statement that managed backups, point-in-time recovery, exports, and alerting are in place (format in docs/technical/ci.md)
BACKUP_ENCRYPTION_KEY Secret Encrypts daily exports. Keep an offline copy: without it no export can be restored.
STAGING_BACKUP_DATABASE_URL Secret Read-only connection for pg_dump (TLS)
BACKUP_R2_API_TOKEN Secret Object read/write on the backup bucket only
STAGING_WEB_URL Variable Staging Pages URL for the smoke test
BACKUP_BUCKET Variable R2 bucket name. Add a 35-day lifecycle rule.
PG_CLIENT_MAJOR Variable Optional pg_dump major version (default 17, must be ≥ the server's)

Settings that live in the app, not in config

The firm name, timezone, currency, invoice and receipt prefixes, upload limit, and "due soon" window are stored in the database. An administrator edits them under Firm settings. See Administration.
