When something goes wrong

  • Look up the message you see in Troubleshooting.
  • Not sure what a word means? See the Glossary.
  • Still stuck? Tell your administrator what you did, what you expected, and the request ID shown in the error message.

How to read this help

  • Button text is shown exactly as it appears in the app. Navigation items are written like Clients → New client.
  • Role badges show who can do something: Administrator Manager Consultant Billing Read-only. An Operator is the person who runs TaxDesk's servers for the firm, not an app role.
  • The Help link in TaxDesk opens the page for the screen you are on. The ◐ button switches light and dark mode, and ⎙ prints the current page.
