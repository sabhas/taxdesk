UAT scenario catalogue

All scenarios covering every story from TD-001 to TD-710: the happy path, plus the refusals and edge cases that prove the rules hold. Record a result for each, then export a CSV for Sprint Review sign-off.

How to run it

  1. Prepare the environment with Build a training environment. Write the environment and the release SHA from /health in the toolbar.
  2. Filter by role and sign in as that role's test account, so you change accounts less often.
  3. For each scenario choose Pass, Fail, or Blocked, and add notes. For a failure, include the request ID from the error and what you saw.
  4. Results are saved in this browser only. Use Export CSV regularly and attach the file to the Sprint Review or defect ticket.
Positive and negative scenarios

Negative scenarios pass when TaxDesk refuses the action or handles the failure safely. A negative scenario that lets the action through is a failure, and usually a security defect: report it immediately.

Operator scenarios need deployment access. Scenarios marked "Any role" can be run with any signed-in account. Link straight to one role with scenarios.html?role=billing.
