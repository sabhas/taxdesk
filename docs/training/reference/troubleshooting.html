Troubleshooting

Symptoms, causes, and fixes, starting with what staff see, then operator problems. Always note the request ID from an error message: it links straight to the audit event and the server log.

Staff-facing problems

Symptom Likely cause Fix
Authenticator code always rejected The phone's clock is wrong, or it is the wrong account in the app Turn on automatic time, and check the account label. Otherwise use a recovery code.
"Too many sign-in attempts. Wait a few minutes and try again." Repeated failures (10 for the account, or 30 from the network, within 15 minutes) Wait 15 minutes. If it is not you, tell an administrator.
"Sign-in verification is not configured" Turnstile was triggered, but the environment has no Turnstile keys Operator: set TURNSTILE_SITE_KEY and TURNSTILE_SECRET_KEY
Activation or reset link refused Already used, or older than 30 minutes Administrator: Reset link creates a new one
Signed out unexpectedly 30 minutes idle, the 12-hour limit, or a role, password, MFA, or status change Sign in again. Repeated surprises: check audit history for the user.
"Someone else saved this client" / a case conflict A colleague saved first (HTTP 412) Review their change, then save over it or discard yours
A status button is greyed out The checklist is not complete or verified, or the move is not allowed Read the reason under the button
"Link and verify a … document before completing this item." The required item needs a verified document Upload and link it, then ask the reviewer to verify it
A consultant cannot see a client or case They are not its assigned manager, consultant, or reviewer A manager assigns them
"Document storage is unavailable" OneDrive outage, or consent revoked Wait for short outages. Administrator: Reconnect storage.
File refused before upload Unsupported type, unsafe name, or over the size limit Convert to PDF/JPEG/PNG/DOCX/XLSX/CSV, rename, or split
Document shows "Missing in storage" The file was deleted or moved in OneDrive outside TaxDesk Recover it from the OneDrive recycle bin, or upload it again. Run reconciliation.
Payment refused The amount is zero, negative, or more than outstanding Check the outstanding amount. For a reversal, ask a manager.
"PDF could not be stored" Storage was down when the invoice was finalized Generate PDF again once storage is healthy
Cannot void an invoice It has net payments A manager reverses the payments first
"TaxDesk is temporarily unavailable" The API cannot be reached Try again. If it persists, tell the operator, with the time it happened.

Operator problems

Symptom Cause Fix
Feature returns 503 A Worker secret is missing (MFA, client, or storage keys) wrangler secret list --env <env>, set the missing one, redeploy
Storage page says not configured (STORAGE_NOT_CONFIGURED) No ONEDRIVE_CLIENT_ID Set it in the environment's vars and redeploy
AADSTS50011 during the storage connection The redirect URI does not match Register exactly <APP_PUBLIC_URL>/settings/storage/callback
AADSTS65001 / consent_required Consent not granted Grant consent for the firm account
Consent fails on Files.ReadWrite.AppFolder Added as an application permission instead of delegated Fix the app registration
Activation links point to the wrong host APP_PUBLIC_URL unset or wrong Set it to the web host and redeploy the API
Database requests fail locally; /health fine Postgres not running, or a wrong local connection string Start Postgres; check .env and the Hyperdrive override
db:migrate:verify checksum mismatch An applied migration file was edited Revert it. Make a new migration, and run db:migrate:manifest for new files.
permission denied for schema public The app role cannot create the ledger table Grant the schema permissions, or run the first migration as the owner
The web app shows a 503 for /api on Pages Missing or wrong API service binding Check packages/web/wrangler.toml and the Pages project's binding
auth:bootstrap refuses Already bootstrapped (by design) Use Users or auth:recover
Everyone's MFA broke after a deploy MFA_ENCRYPTION_KEY changed Restore the original key from the offline store. Otherwise run disable-mfa for each user.
Duplicate check misses obvious CNIC duplicates CLIENT_IDENTIFIER_INDEX_KEY changed Restore the original key; re-index before any rotation
Posture or export issue opened in GitHub Stale evidence, or a failed or old export See Backup, restore and lockouts
ci:secrets fails A token-like string in a tracked file Remove it, or use an obvious placeholder (<…>, EXAMPLE)
Rollup native-module error after switching machines node_modules built for another OS or CPU just reinstall-force or pnpm install --force

Reporting a defect

  1. What you did (steps), what you expected, what happened.
  2. Role and username of the test account (never a password).
  3. Environment, the release SHA from /health, and the time (with timezone).
  4. The request ID from the error message.
  5. The UAT case ID, if the defect came from the catalogue.
  6. Screenshots of synthetic data only.
