Glossary

Terms used in TaxDesk and in this guide.

Term Meaning
Audit historyThe permanent, append-only record of who did what and when. Administrators search it.
Blind indexA keyed fingerprint of a CNIC/NTN that lets TaxDesk find exact matches without storing the number in readable form
Case (TC-…)One client's work for one service and tax year
Checklist itemA step or document a case needs. It can be required, and can need reviewer verification.
Client (CL-…)An individual or business the firm serves
Client groupA group head (itself a client) and the clients linked to it through Parent client. One level deep; used to filter clients, cases, and invoices and to total a group's billing.
Combined invoiceOne invoice addressed to a group head that bills work for the head and its members. Each line names the client it is for; the PDF shows a subtotal per client. Paid as a whole by the head.
CNICComputerized National Identity Card number: 13 digits, required for individual clients. Always masked.
Dry runAn import check that shows what would happen, without writing anything
Due soonAn open case due today or within the next 7 days (the dashboard uses the firm's due-soon setting)
ETag / version checkA record's version number. Saving an older version is refused (HTTP 412) so nobody overwrites a colleague's change.
external_refA record's ID in the old system, used by imports to link rows and make re-imports safe
FinalizeTurn a draft invoice into a numbered, frozen one
/healthAn endpoint reporting only the environment, release version, and request ID
HyperdriveThe Cloudflare service that pools the Worker's database connections over TLS
Idempotency keyA unique key sent with money, upload, and import commands so a retry never repeats the effect
Lineage CSVImport export mapping each source row to the TaxDesk record it created or updated
MFA / TOTPMulti-factor authentication with time-based six-digit codes from an authenticator app
Minor unitsMoney stored as whole paisa (PKR × 100) to avoid rounding errors
NTNNational Tax Number: required for business clients, optional for individuals. Always masked.
OperatorA person with deployment access (Cloudflare, database, GitHub). Not an app role.
PITRPoint-in-time recovery: the database provider's ability to restore to any moment
PreparerThe case's primary consultant, who completes checklist items
Problem DetailsThe standard JSON error format every API error uses, including a requestId
Reconciliation(Storage) checking every document record against OneDrive. (Import) checking imported totals against the source.
Recovery codeOne of ten single-use codes that replace an authenticator code when the phone is unavailable
Request IDA unique ID for every API call, shown in errors and stored in logs and audit
ReversalA linked entry that cancels all or part of a payment, without editing the payment
ReviewerThe person who verifies checklist items and case documents. Must differ from the preparer.
RTORecovery time objective: TaxDesk's target is four hours
ServiceSomething the firm sells, with a default fee, deadline, and workflow
Sprint ReviewThe meeting where stories are demonstrated on staging and accepted
TurnstileCloudflare's "are you human" check, shown after repeated failed sign-ins
UATUser acceptance testing: checking the software does what the firm needs
VoidPermanently cancel an invoice that has no net payments. It stays visible.
WorkerThe Cloudflare Worker running the TaxDesk API
Workflow template / versionThe statuses, transitions, and checklist a case follows. Published versions never change.
